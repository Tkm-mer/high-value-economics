# 专业咨询服务优秀案例

 | **字段** |  | **专家出题填写** | 

 | **任务名称** |  | 二十年成熟制造企业发展瓶颈、组织体系重构、流程提效与内部管理提升的解决方案 | 

 | **任务类型** |  | 方案设计/规划 | 

 | **L1行业** |  | 专业咨询服务 |

 | **题目-文字** |  | 根据成立二十年企业，近三年经营数据、内部组织流程、质量成本数据、组织人员现状、现有生产设备台账、固定资产折旧等，全面深度诊断成熟企业结构性问题，企业要求年度刚性费用降本6%、无设备采购预算、禁止裁员降薪、交付提升质量和速度、改革无冲突矛盾、存量市场无新增方向的多重困难下，完成全套可落地、可闭环的组织突围方案，要求输出以下内容：
1、需要系统性诊断公司20年成熟期经营瓶颈，从重点部门的流程、制度、责权、成本、品质、交付、人效、组织等维度寻求根因，输出一份诊断报告；
2、需要梳理公司各项规章制度、各审批流；识别冗余流程、无效审批、断点流程、交叉权责，完成流程精简、流程重构、流程标准化、闭环化优化；输出人力资源薪酬、绩效、培训、各项管理制度综合至少5份以上优化的规章制度文件；
3、平衡短期交付稳定与长期体系改革，设计分阶段改革任务表，规避改革阵痛带来的订单延误、品质波动、产能下滑风险；输出三阶段改革落地任务表，需要总计划任务一份，三个分阶段任务三份；
4、重构部门权责体系，解决推诿内耗、职责空白、多头管理问题，提升整体运营流转效率；输出各职能部门部门权责，生产内部岗位SOP，新的组织架构图；
5、根据年度降本要求输出一份年度费用降本6%的降本计划实施方案；
6、根据内部组织流程、交付提升质量，满足费用降本6%的指标要求，进行生产体系梳理、质量业务梳理、供应链业务梳理、生产业务总图； |

 | **考点** |  | 一、如何利用专业知识来识别成熟期企业结构性瓶颈的深度诊断能力，需要用专业的诊断方法和工具，区别于普通初创企业问题；
1、采用科学的诊断工作，来诊断制度流程的冗杂性、简化制度流程，各部门部门权责；
2、输出一份完整的诊断报告；

二、从哪几个方面来分析和处理降本与保质、改革与维稳、短期交付与长期变革多重困难的博弈平衡能力；
1、从近两年的质量成本分析质量成本增高的具体原因；
2、在改革与维稳的方面有哪些可落地的措施，具体分三个阶段来进行改革，三阶段任务表；

三、破解老组织变革阻力，设计柔性落地改革方案，而非激进理论改革；
1、利用专业诊断工具精准定位老组织的核心阻力；
2、柔性改革核心落地原则，如何来做，区别于激进改革；
3、如何依托诊断体系、博弈平衡、流程体系三大底层支撑来完成柔性改革完整落地实施方案；

四、实现组织优化可量化、可落地，有明确增效、降本、提效数据指标；
1、列出降本量化指标；（对应结构性降本）
2、列出提效量化指标；（组织与流程效能提升）
3、增效量化指标；（长期经营增益）
4、完成全年费用成本降低6%的目标；
5、具体拆解6%的降本项目；

五、从各个部门梳理流程、规章制度、岗位职责搭建企业长效运营迭代体系，彻底突破二十年增长瓶颈，形成可持续经营闭环；
1、如何梳理各个部门的流程制度；输出新的薪酬管理制度、绩效管理制度、培训制度等五份以上制度文件；2、采用哪种方法进行岗位职责的确定；输出各职能部门的部门责权；输出生产岗位的sop；
3、制作新的组织架构图；
4、对生产、质量、供应链进行业务梳理，输出三份业务文本，输出生产业务总图； | 

 | **作答思路** |  | 1、全面研读企业近三年经营数据、流程制度、质量成本数据、人员结构数据，梳理成熟期企业典型衰老症状，选择适配成熟期企业的核心诊断工具；
2、分层分类诊断经营瓶颈、流程瓶颈、组织瓶颈、成本瓶颈、活力瓶颈，定位深层根因；从数据到问题、从表象到根源，避免片面诊断；
3、梳理全局组织流程，坚持核心原则：结构性降本、精准化控本、价值化保质，剔除冗余、补全断点、明确权责边界，重构标准化高效运营体系；
4、针对老员工、老团队保守固化问题，设计分层宣导、试点先行、梯度改革的落地策略，降低改革阻力，小步迭代、分层推进、平稳过渡、风险可控；
5、规划短期维稳、中期提效、长期破局的三阶段改革路线，保障交付稳定的同时完成体系升级；短期保底线、长期破瓶颈、取舍有优先级、资源精准分配；
6、聚焦无设备、无人裁员、无增收空间的三重约束，深挖隐性运营降本增效点，精准对标6%年度费用降本红线，确保指标全额达标；
7、整合所有诊断成果、优化方案、矛盾权衡策略、风险预案、落地路径，输出完整的企业运营突破方案。 | 

 | **标准答案-文字（如有）** |  | 输出《二十年成熟期企业运营瓶颈诊断与降本增效破局方案》，包含全维度瓶颈深度诊断报告、流程重构优化方案、6%年度费用降本量化落地清单、权责梳理与内耗解决方案、柔性变革落地策略、三阶段改革任务表、长效运营迭代闭环机制，实现在多重困难约束下，全额达成降本、提质、提速、稳队、增效、破局的完整落地成果。
