<title>一个行业，怎么轻松出满 8 道高经济价值难题？</title>

> 
**大家都在自己深耕的领域里出题，如何拆出 8 道方向不重复、道道够难的题？**
看完这篇，您应该能对应自己的专业领域，思考整理出 8 个互不重复的出题方向。

# 一、出题标准

| 要点 | 口径 |
|-|-|
| **一句话标准** | 这件事交给 AI 做完，您愿意付 100 块；原本人工要干 16 小时以上。 |
| **合格线** | 放到当前Sota模型上跑，得分率 ≤ 50%；执行轮数 ≥ 50 步，或运行时长 > 40 分钟（二选一）。 |
| **重点要交的五项内容** | 题目 Prompt、附件材料、标准答案、考点Rubrics、作答思路。 |

# 二、核心方法：怎么在一个领域里找出8道不重复的题？

这是今天最核心的部分。选定领域后，不要一道一道拍脑袋想方向，可以先用下面五种拆法，把您的领域列成一张**方向清单**，每个方向就是一道题。

这五种拆法有一个共同特点：**您只需要深耕自己这一块，就能找出 8 道题**，不需要跨岗位、跨环节。而且每道题用到的业务材料天然不同，不会重复。

| 拆法 | 核心逻辑 | 多行业举例 |
|-|-|-|
| **按业务场景拆** | 同一个岗位，面对不同的业务场景或产品条线，每个场景的材料和关注点完全不同 | **法律：**民商事诉讼、刑事辩护、知识产权诉讼、破产重整  
**医疗：**内科门诊、外科手术、急诊救治、慢病管理  
**金融：**产业并购、跨境并购、借壳上市、债务重组 |
| **按工作任务拆** | 同一个领域里，不同类型的工作任务，交付物和工作环节完全不同 | **法律：**合同审查、法律意见书、尽职调查、诉讼代理  
**教育：**教案编写、试卷出题、作业批改、学情分析  
**互联网：**产品需求文档、用户调研、数据分析、版本迭代 |
| **按分析视角拆** | 同一个问题，从不同维度切入分析，每个视角需要不同的数据和材料，考点完全不同 | **教育：**教学效果、学生学情、课程设计、家校沟通  
**医疗：**症状学、检验指标、影像学、鉴别诊断  
**互联网：**用户行为、数据指标、竞品对比、用户反馈 |
| **按客户类型拆** | 同一个岗位，面对不同部门的同事沟通，对不同类型的客户或服务对象沟通，每类客户的需求、材料和难点完全不同。不需要您跨职级，只需要在自己的岗位上区分不同的服务对象 | **法律：**企业客户、个人客户、政府客户、公益组织  
**教育：**小学生、初中生、高中生、成人学员  
**医疗：**儿童患者、老年患者、慢病患者、急诊患者 |
| **按精准考点拆** | 答案相对唯一，有明确的对照标准（数字、规则、是/否判定），模型不能"怎么答都对" | **核算计算：**金融税负测算、法律违约金计算、医疗药物剂量计算  
**合规判定：**法律合同合规审查、医疗用药适应症判定、互联网隐私合规判定  
**数据核对：**多份文件间数据一致性核对  
**流程规范：**审批环节与必备材料清单  
**阈值红线：**数值是否超过标准、是否触发 |

> 
**用法：**先把您行业领域里的关键场景、任务、角度、客户类型列出来，再从五种拆分方法里挑两三种搭配着用。凑够 8 个方向，五期的题目清单就有了——方向不重复，每道题的材料也不同，后面只管把每道题的具体内容填上就行。

# 三、实战示范：以文旅景区运营为例，怎么排出 8 道题？

光说方法可能有点抽象，我以"文旅景区运营"这个细分领域为例，给大家排了 8 道题。注意，这 8 道题全都在景区运营这一个领域里，不需要您跨领域——但每道题的场景、任务、材料完全不同，而且每道题都需要多个附件交叉核对、多阶段交付物，复杂度足够撑起高经济价值难题的标准。

| 序号 | 拆法 | 题目方向（含附件与交付物） | 难点从哪来 |
|-|-|-|-|
| 1 | 业务场景·节假日大客流 | 基于历年节假日客流数据 + 天气预报 + 交通管制信息 + 景区承载量标准 + 应急预案，制定节假日大客流应对方案，含客流预测、分流路线、人员调配表、物资清单、应急响应流程 | 多附件交叉 + 多阶段工作流 |
| 2 | 业务场景·新景区开业筹备 | 基于景区规划方案 + 招商进度 + 人员编制 + 预算 + 工程进度表 + 竞品数据，制定开业筹备倒排计划，含工程验收、商户入驻、人员培训、试运营、正式开业各阶段的交付物和时间节点 | 多阶段工作流 + 跨格式读取 |
| 3 | 业务场景·日常运营管理 | 基于月度运营数据（客流/营收/投诉）+ 商户经营数据 + 设备维护记录 + 游客满意度调查，制定月度运营分析报告和下月计划，含指标分析、问题诊断、改进措施、资源调配方案 | 提炼数据 + 多维度分析 |
| 4 | 工作任务·大型活动策划 | 基于品牌调性 + 客群画像 + 预算 + 场地平面图 + 历史活动数据 + 供应商报价 + 审批要求，制定大型主题活动完整执行方案，含活动创意、流程设计、宣传推广、招商方案、预算明细、风险预案 | 创意复杂度 + 多约束推导 |
| 5 | 工作任务·票务定价策略 | 基于历年票务销售数据 + 竞品价格 + 游客消费行为分析 + 成本结构 + 季节性波动 + 会员数据，制定年度票务定价和促销方案，含票价体系、淡旺季定价、联票策略、会员体系，并测算各方案营收影响 | 核算计算 + 多因素平衡 |
| 6 | 客户类型·研学团队客群 | 基于研学市场数据 + 学校需求调研 + 课程标准 + 景区资源 + 安全规范 + 合作机构信息，设计研学团队专项产品和服务方案，含课程设计（分学段）、行程安排、师资配置、安全保障、定价策略、合作模式 | 特定客户需求 + 多约束推导 |
| 7 | 精准考点·经营数据核算 | 基于财务报表 + 票务系统数据 + 商户结算单 + 成本明细 + 预算执行表 + 各业态营收明细，核算并核对核心经营指标（营收/成本/毛利/客流/客单价/各业态占比/预算完成率），找出多份数据间差异并说明原因，输出经营分析报告 | 核算计算 + 数据核对 |
| 8 | 精准考点·安全合规审查 | 基于安全生产法 + 旅游安全规范 + 消防标准 + 景区安全管理制度 + 设备检测报告 + 隐患排查记录 + 应急预案 + 各区域平面图，对景区进行全面安全合规审查，逐项核查各区域/设备/流程是否合规，列出问题清单、风险等级、整改建议和时限，输出审查报告 | 判定合规性 + 多附件交叉稽查 |

大家看这 8 道题，全都在文旅景区运营这一个领域里，但方向完全不同：前 3 道用"按业务场景拆"，分别对应节假日大客流、新景区开业、日常运营三个场景；第 4、5 道用"按工作任务拆"，分别是大型活动策划和票务定价策略；第 6 道用"按客户类型拆"，针对研学团队这类特定客群设计专项产品；第 7、8 道用"按精准考点拆"，分别是经营数据核算和安全合规审查。

每道题用到的材料、难度杠杆也各有侧重——这就是先列方向清单的好处，不会出着出着发现两道题其实是一道。

当然，这是文旅景区运营领域的例子。如果您是做法律的、做教育的、做医疗的、做互联网的，方法是一样的。

# 四、方向定了之后，怎么把一道题出难？

速查表如下：

| 增加难度方法 | 一段话自检 |
|-|-|
| **Prompt 链路** | 任务是不是拆成了一环扣一环的多阶段？模型能不能一步跳到答案？能跳，就说明链路不够长。好的链路应该像必经流水线：先定口径，再逐条算明细，再出方案，再做压力测试，最后安排执行；上一步结果必须是下一步输入，不可合并、不可绕行。 |
| **附件纠缠** | 抽走任意一份附件，模型还能答吗？能答，说明附件之间没"咬"住。好的附件应该按来源分开、格式不统一、互相依赖、互相印证，并埋冲突和仲裁依据：签发优先于草稿、合同优先于会议纪要、截止日前批优先于事后补签。 |
| **隐性考点** | 考点里有没有这个领域"没写在题里、但行内人都知道"的规矩？考点是不是写成“考虑了含税差异”这种笼统话？是，就压不住分。好的考点要具体到数：如“三季度不含税收入 1284.6 万元，误差≤0.1 万元；直接用含税 1451.6 万元的不得分”，一条只查一件事，一个坑配一条考点。 |
| **必经工作量** | 模型能不能靠一份汇总表、一份报告、按比例缩放就交差？能，说明轮数和时长不够。好的工作量要藏在原始明细里：逐笔逐户逐 SKU 给结论，汇总对回明细；排程真求解、代码真跑测试；交付物拆多份且数字一致；压力情景必须重算；最后加自查对数表。 |
| **多规则组合** | 同一批对象是不是同时命中多个规则，且优先级随组合变化？模型是不是总能算出一个漂亮方案？能，说明难度不够。好的题要加入组合规则、例外、状态边界。 |
| **关键判断标准自推** |  题面是不是直接告诉模型该看哪个指标？模型能不能沿着现成排行榜选“综合最强”？能，说明它解决的不是当前最关键问题。好的题总任务明确，但关键判断标准要模型自己推：从当前瓶颈反推真正标准，再从延期、积压、产能利用率、停产记录里找证据。 |
| **难度阶梯与降低送分** | 考点是不是大半是格式、结构、常规计算、常识结论？模型是不是靠这些就能拿到接近一半分？是，难点埋得再好也压不到 50 分。好的题按 L1—L6 加码：L1 信息加工、L2 逐条处理、L3 辨别仲裁、L4 约束优化、L5 动态重算、L6 立场决策；送分考点控制在约三成以内。 |
| **标答与试跑校准** | 出题人自己用最顺手办法能不能做对？SOTA 得分、轮数、时长有没有达标？不达标，就说明题还没成型。好的流程是固定工序：笨办法自测 → SOTA 试跑 ；得分 >50、轮数 <50、时长 <40、模型错了没扣分，都要对照诊断改prompt和rubrics。 |
| **迭代铁律** | 改题是不是在加固定步数、重复打开同一文件、每步发进度、派子代理、写上百页？是不是把不相干小事拼盘？是，就是凑量。好的返修需要动“材料”和“结构”：换原始导出、加冲突口径、拆交付物、加真求解/真测试、要求情景重算，而不是加硬性轮数。 |
| **合规与禁止清单** | 有没有用 AI 出题、脱敏、生成考点/附件/标签？有没有跨行业、同质化、依赖真实平台账户？有，就不结算或不合格。好的题必须真实行业需求、单轮、附件全部可调用、同一专家 8 题有明确差异。 |

另外提醒一点：**找方向不等于降低难度。**每个方向里的题都要过同样的难度线——得分率 ≤ 50%，轮数 ≥ 50 步或时长 > 40 分钟。不要因为拆了 8 道，就把每道题都出得很浅。

# 五、避坑：出 8 道题最容易踩坑的 4 个地方

1. **方向撞车：**看着是 8 道题，其实是同一套 Prompt 换汤不换药。提交前对照方向清单，确认每个方向的场景、任务、交付物真的不同。
2. **前紧后松：**前面认真后面凑数。前面几道精雕细琢，后面赶数量凑题。8 道题是一个整体，每一道都得过同样的难度线。建议先把 8 个方向都排好，再一道一道填内容。
3. **隐性考点太少：**这是最普遍的问题。考点全是"要包含分析""要给出建议"这种表面话。可以想想您行业领域里的"默认规矩"——没写在明面上、但行内人都遵守的东西，才是压分的关键。
4. **附件不纠缠：**附件列了五六个，但模型只用其中一个就能答完，其他的都是摆设。记住，附件是用来"考"的，不是用来"堆"的。每一份附件都应该在解题过程中被用到，而且最好是互相印证、互相依赖的。

# 六、提交前，对着这张表过一遍

| 检查项 | 达标标准 |
|-|-|
| **五件套齐全** | Prompt、附件、作答思路、标准答案、考点 Rubrics，一份不缺。 |
| **方向不重复** | 8 道题的场景、任务、交的内容互不重叠。 |
| **增难法都在** | 多阶段链路、附件互相纠缠、有隐性考点等增加难度的方法都在。 |
| **难度都达标** | 每道题都过难度线（得分率 ≤ 50%，轮数 ≥ 50 步或时长 > 40 分钟），不是只有前几道够难。 |
| **自测过一遍** | 先让模型跑一遍，达标再提交。不要等到质检环节才发现难度不够。 |

# 七、出题前先做这 4 步

1. **用五种方法列出 8 个方向**——先写题目方向，不写细节。这一步大概花 20 分钟。
2. **确认每个方向的材料都不同**——避免 8 道题用重复的业务材料。
3. **挑您最熟的那个方向开始填内容**——题目、附件、答案、考点，一道一道来。
4. **第一道做完，对着速查表自检一遍**——找到手感，剩下 7 道会越出越快。

> 
最后说一句：不用追求一上来就出完美的题。先完成，再完美——8 道题的量本身就是优势，早提交、早进入前三阶段质检流程，早的老师返修时间更充裕。出的过程中遇到任何卡点，群里随时问，我们一起把题目打磨好。加油，期待大家的好题！
