# 法律服务优秀案例

 | **字段** |  | **专家出题填写** | 

 | **任务名称** |  | 合肥劳动争议案件裁判特点与审查细节知识库建设——归纳合肥法院劳动争议案件的判决特点与审查细节，压缩律师准备劳动案件材料的时间 | 

 | **任务类型** |  | 客户与专业项目交付（案件复盘与办案知识库建设） | 

 | **L1行业** |  | 法律服务 | 

 | **L2行业** |  | 诉讼与仲裁 | 

 | **L1职业** |  | 法律与合规 | 

 | **L2职业** |  | 律师 | 

 | **题目-文字** |  | 你是负责该专项的劳动法律师。请根据唯一附件“合肥劳动争议案件判例15份”，对全部15份判决书完成全量复盘，归纳合肥法院在劳动争议案件中的判决特点与审查细节，并沉淀为一套可直接用于办案准备的知识库。请以五份配套交付物形式交付，内容需可追溯、可复算、可直接执行。
任务一：文件盘点、案件簇识别与案件级全量提取。建立文件总目录，逐份核对文件名、案号、法院、裁判日期、可读性与脱敏一致性；从判决书记载的仲裁裁决书编号、“双方均不服同一仲裁裁决分别起诉”“并案审理”“另案诉讼”等信息中建立案件簇与程序关系，统计时同时保留“文书数”“程序案件数”“实质纠纷数”三种口径。随后逐案提取案号、法院、裁判日期、案由、当事人身份类型（劳动者／用人单位／个体工商户经营者／分公司／破产管理人／第三人）、入职时间、离职或解除时间、解除方式与提出方、书面劳动合同签署情况、社会保险缴纳情况、仲裁前置及仲裁结果、争议请求项、答辩要点、法院认定的法律关系性质、裁判结果与费用负担。
任务二：诉讼请求项级拆分与裁判金额逐项复算。把每案的诉讼请求（或仲裁请求）拆到最小可判断单位：确认劳动关系及其存续期间、支付欠付工资或劳务报酬、未签订书面劳动合同双倍工资差额、加班工资、未休年休假工资、经济补偿金、违法解除或违法终止赔偿金、返还社会保险补贴、返还垫付的社会保险费、工伤保险待遇（细分为一次性伤残补助金、一次性工伤医疗补助金、一次性伤残就业补助金、停工留薪期工资、医疗费、住院伙食补助费、鉴定费）、出差补贴、报销款、办理社会保险关系转移手续、办理人事档案转移手续等。一项请求一行，标注提出方、主张金额、法院处理方式（全部支持／部分支持／未支持／未作实体处理）与支持金额。对每一项请求按法院说理中列明的公式逐步复算，写明计算基数、基数口径来源、计算期间起止、折算天数或月数和最终数额，并与裁判主文逐项比对，差异单列说明。
任务三：裁判特点归纳与审查细节、举证责任梳理。归纳合肥法院的判决特点，每个特点须写明结论、依据的案件编号与原文定位、成立条件和反例或例外。归纳至少覆盖：（1）主体资格与法律关系性质的审查顺序；（2）实际用工主体的识别方法；（3）双倍工资差额的基数口径与计算期间；（4）工资标准的证据顺位与当事人自认的效力；（5）社会保险约定无效后的返还路径；（6）经济补偿金与赔偿金的基数差异与年限折算；（7）未休年休假工资的折算与举证；（8）加班事实与加班工资的认定及已付抵扣；（9）工伤待遇的承担主体与举证责任；（10）用人单位内部规章制度和内部标准的证明力；（11）事实推定规则（如工资发放周期与入职时间的推定）；（12）程序性事项（仲裁前置、不予受理、并案审理、缺席审理、仲裁时效）。同时按争点建立“待证事实—举证责任方—所需材料—材料由谁掌握—缺失或拒不提供的后果—审查细节”表，须特别写明哪些材料属于用人单位掌握管理、不提供时承担不利后果，哪些事实必须由劳动者自行举证，并对“劳动合同原件遗失”“工资表无劳动者签字”“考勤由用人单位掌握”“以《劳务合同》名义用工”“员工登记表／保密协议／员工手册能否替代劳动合同”“社保缴费基数与劳动合同约定工资不一致”等高频情形给出可直接执行的审查动作。
任务四：现行规则核验、典型案例复核与办案材料准备清单。对上述特点所涉规范逐一核验现行有效版本，记录规范名称、条文号、生效时间和适用边界，范围至少包括《中华人民共和国劳动法》《中华人民共和国劳动合同法》及其实施条例、《中华人民共和国劳动争议调解仲裁法》《职工带薪年休假条例》《企业职工带薪年休假实施办法》《工伤保险条例》《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》、《关于确立劳动关系有关事项的通知》（劳社部发〔2005〕12号）以及安徽省地方性规范（《安徽省劳动合同条例》《安徽省实施〈工伤保险条例〉办法》等）。从15份判决中筛选能说明裁判差异或审查细节的案例并形成原文索引。最后输出接案至结案的材料准备清单，按“必交材料／可补材料／无法取得即承担风险的项”三级分类，按案件类型（双倍工资差额类、被迫解除与经济补偿类、违法解除或违法终止类、超龄用工类、社会保险争议类、工伤待遇类、个体工商户或分公司主体争议类、加班与年休假类）给出一次性取材料顺序、常见返工点及模板化提速点。
交付物：（1）《合肥劳动争议判例全量复盘台账.xlsx》——一案一行，至少设置文件盘点、案件主表、请求项明细、金额复算与差异、字段字典、统计汇总工作表；（2）《劳动争议审查要点与举证责任分配表.xlsx》——一争点或一请求项一行，含待证事实、举证责任方、所需材料、材料掌握方、缺失后果、审查动作和对应案号；（3）《合肥劳动争议裁判特点与审查细节分析报告.docx》——建议正文10000－16000字，含执行摘要、数据范围与方法、法律关系定性与主体资格、请求项与金额基数口径、举证责任与证据采信、程序性审查、典型案例、风险边界和办案建议；（4）《劳动争议办案材料准备清单与提速方案.docx》——按案件类型编写立案材料清单、举证材料清单、金额计算表模板、程序节点表和常见返工点；（5）《典型案例与原文定位索引.xlsx》——统一编号，列明代表性、争点、关键事实、法院处理、可复用审查动作、所在文件与段落定位及关联请求项编号。
统一口径：审查基准日以实际提交日填写，法律规则以该日现行有效版本为准；案件范围为唯一附件内的15份判决书，全量处理，缺件或无法解析的仍须列入盘点表并说明处理，不得自行换案；分析单位同时保留文书、程序案件、实质纠纷、诉讼请求项四种，不可混用；事实层级依次区分当事人主张、答辩意见、证据记载、法院查明、法院说理和裁判主文，可相互印证但不得直接替代；结果口径按全部支持、部分支持、未支持、未作实体处理分类，分类规则写入字段字典；金额口径分别记录主张金额、法院认定基数、裁判支持金额，无执行或履行材料的“实际履行金额”填“附件未载明”；隐私口径仅使用附件中的脱敏名称与案号，不尝试恢复真实身份，成果中不得出现身份证号、住址、银行账号、联系方式等非必要个人信息；无法确认的字段填“附件未载明”，记载冲突未排除的填“材料记载冲突”，复算与主文不一致的填“复算差异”并单列说明。 |

 | **考点** |  | 1. 文件盘点与计数口径：全量识别15份判决书，准确列出文件名、案号、法院、裁判日期、可读性与脱敏状态，说明纳入与排除处理；正确识别双方互为原被告的并案审理情形及判决书中记载的关联案号，区分文书数与实质纠纷数，不重复计算。
2. 来源定位与事实分层：案件字段、请求项、金额结论和典型案例均可追溯至具体案号和判决书段落；严格区分原告诉称、被告辩称、证据记载、法院查明、法院说理与裁判主文，不以单方主张替代法院认定。
3. 案件级提取与请求项拆分：当事人身份类型、入职与离职时间、解除方式与提出方、合同签署情况、社保缴纳情况、仲裁前置情况等字段完整，关键字段准确率原则上不低于95%；一项请求一行，正确区分工资、双倍工资差额、加班工资、年休假工资、经济补偿、赔偿金、社保补贴返还、工伤待遇各明细项、差旅补贴、报销款、手续办理等最小请求单位，不以整案胜负覆盖部分支持或未处理情形。
4. 金额复算：逐项复算并写明基数、口径来源、期间和公式；复算与裁判主文一致，或能用差异清单说明不一致原因。重点覆盖21.75日工资折算、年休假当年度折算、超龄用工报酬折算、双倍工资差额的计算期间与基数、加班工资150%/200%/300%分档与已付抵扣、经济补偿年限折算、工伤待遇倍数与月数。
5. 法律关系定性与主体资格审查：正确区分劳动关系、劳务关系、超龄用工、用工主体责任、工伤参保关系，不以合同名称判断性质；准确识别法定退休年龄、个体工商户成立与注销时间、经营者身份、分公司与总公司、破产管理人等主体问题；在挂靠、委托经营、案外人招聘发薪等情形下正确判断实际用工主体。
6. 双倍工资差额与工资标准口径：正确写出计算期间起止规则与11个月封顶；正确区分固定工资构成与提成、社保补贴、加班费等浮动项目；正确排列工资标准的证据顺位（合同约定、工资表分项、银行流水、社保或公积金缴存基数、聊天记录自认），正确评价当事人自认的效力。
7. 社会保险、经济补偿与赔偿金：正确适用约定不缴纳社保无效的规则并核算补缴后应返还的社保补贴和垫付的个人缴费部分；正确区分经济补偿与赔偿金的适用情形和基数口径，正确适用年限折算规则和二次固定期限合同情形。
8. 年休假与加班工资：正确适用累计工作年限、当年度折算方法、21.75折算日和200%口径并说明举证责任归属；加班工资须按150%/200%/300%分档、逐笔扣减用人单位已付部分，并正确评价打包工资与按日计酬情形。
9. 工伤待遇与内部制度证明力：正确列出工伤待遇各明细项、计算基准（统筹地区职工月平均工资、本人工资）、倍数与月数，正确分配承担主体的举证责任；正确评价用人单位内部规章、报销标准、薪酬管理办法的证明力，区分公示制度与单方制作材料。
10. 推定规则、程序性审查与规则核验：正确归纳事实推定规则与举证责任分配，明确属于用人单位掌握管理而不提供的证据之不利后果；正确梳理仲裁前置、不予受理通知书、并案审理、缺席审理、仲裁时效与起诉期限；按基准日核对规范名称、条文号、生效时间与适用边界，不引用已失效规定，不把单案结论写成普遍规则。
11. 典型案例、材料清单与交付一致性：案例来自附件且选择理由明确，完整呈现争点、关键事实、证据配置、法院处理、请求项结果和可复用审查动作；材料清单按必交、可补、无法取得即承担风险三级分类，给出取材料顺序、常见返工点和模板化提效点；台账、审查要点表、分析报告、材料清单与索引的案件数、请求项数、案号、金额、结果和来源定位一致。
严重错误及一票否决项：（1）大批判决未处理却声称完成全量复盘，或仅抽取若干典型案件代替全量台账；（2）把起诉状、答辩意见中的单方表述直接写成法院查明事实并据此形成结论；（3）同一纠纷的并案审理、关联案号重复计数，导致案件数量、支持率或金额明显失真；（4）虚构附件中不存在的入职时间、工资标准、社保缴纳情况、协议内容或实际履行事实；（5）报告核心数字无法从台账复算，典型案例无法定位到原文，或多份交付物之间出现系统性矛盾；（6）把裁判支持金额直接写成已实际取得的款项，或在无执行、转账材料的情况下推定已经履行。
常见易错点：以判决书标题中的“劳动争议”案由直接认定存在劳动关系，忽略主体资格与实际用工主体审查；把双倍工资差额基数与经济补偿金基数混用同一口径，或用含提成、社保补贴、加班费的总收入计算；双倍工资差额计算期间起算点写错（应为用工满一个月的次日）或遗漏11个月封顶；认为“签订《劳务合同》即不构成劳动关系”，或认为“以项目名义为农民工参加工伤保险即不承担工伤保险待遇”；把年休假折算天数直接取整、把200%与300%口径混用，或忽视累计工作年限需由社保缴纳记录证明；计算加班工资时未逐笔扣减已付部分，或未区分休息日加班当日已发工资与应补差额；把仲裁裁决金额直接抄为法院判决金额而不逐项复算（尤其是法院改按固定工资构成计算双倍工资差额、改按实际履行期间平均工资计算经济补偿的情形）；把“补足工资差额后的月工资标准”与“原约定或原实发工资标准”混用导致加班工资基数错误；在附件没有执行或履行材料的情况下把判决支持金额填写为已实际取得。 | 

 | **作答思路** |  | 1. 从唯一附件总文件夹出发，保留只读原件，自行生成文件目录与唯一编号，核对文件数量、可读性、重复与脱敏一致性，形成盘点表与异常处理记录。
2. 从判决书中提取仲裁裁决书编号、并案审理记载、关联案号、另案诉讼信息，先锁定实质纠纷单位，再确定文书数、程序案件数与实质纠纷数三个分母。
3. 固化字段字典：定义案件、请求项、金额、基数口径、支持程度、程序结果和缺失值口径；先试标2至3份判决并修订字段定义，再全量提取，避免全量返工。
4. 逐份并列提取当事人身份、时间节点、合同与社保情况、诉辩主张、答辩要点、法院认定与裁判结果，保留原文定位。
5. 把每案请求拆为最小可判断单位并统一命名与分类，与案件编号关联，不合并多套请求。
6. 按法院说理中的公式逐项复算金额，写明基数与口径来源、期间与折算办法，与裁判主文逐项比对，差异进入差异清单。关键判断点在于区分“固定工资构成”与“总收入”：双倍工资差额按固定工资构成计算，而经济补偿可能按当事人自认的标准计算，同一案件存在两个基数。
7. 按预设维度聚类相同与相异的处理方式，形成“特点—成立条件—依据案号与原文—反例”结构。关键判断点在于不得把单案表述写成普遍规则，也不得把“法院认为”段落中的法条引用直接当作裁判特点。
8. 按争点组织“待证事实—举证责任方—材料—掌握方—缺失后果—审查动作”，重点区分由用人单位掌握管理的证据（劳动合同、考勤、工资表）与须由劳动者自行举证的事实（累计工作年限、实际提供劳动、解除意思表示）。
9. 只对实际出现的高频争点核对现行规则，逐条记录规范名称、条文、生效时间与适用边界，重点核验近年新施行规则对约定不缴社保的效力、补缴后返还、无固定期限劳动合同、单方解除合法性审查依据的影响。
10. 选择能说明裁判差异或审查细节的案例，逐项回查判决原文，形成统一编号与原文索引。
11. 把裁判特点与审查细节转化为接案、立案、举证、开庭、结算各阶段的材料清单、计算表模板和程序节点表，标注常见返工点与模板化提效点。易错点是清单停留在“应当收集证据”这类空话，而不是落到“接案首日取什么、立案前核对什么、开庭前补什么”。
12. 用案号和请求项编号核对五份成果，检查公式、分母、引用、隐私和重大结论，重大数字做独立复算。 |

一、案件清单与计数口径（金标准）。附件共15份判决文书，对应14个实质纠纷。其中1份判决系劳动者与用人单位均不服同一仲裁裁决分别起诉、由法院并案审理并一并作出裁决（判决书中同时出现两个案号），故文书15份、实质纠纷14个。法院分布：合肥市瑶海区人民法院8份，合肥高新技术产业开发区人民法院3份，合肥市包河区人民法院、合肥市庐阳区人民法院、肥西县人民法院各1份，另有1份为瑶海区人民法院的并案判决。
二、合肥法院判决特点核心要点。
特点1（定性优先）：法院普遍把主体资格与法律关系性质作为第一顺位争点。对已达到法定退休年龄的劳动者认定不成立劳动关系：一件案件中劳动者1968年4月2日出生、2018年4月2日已达法定退休年龄，法院认定属超龄用工，仅就实际提供劳务部分按日折算支持报酬，其余基于劳动关系的主张全部驳回；另一件案件中女职工入职时已达法定退休年龄，法院认定双方为劳务关系，并明确“用人单位招用已达到法定退休年龄但未领取养老保险待遇或退休金的人员，不能由此推定形成劳动关系”。
特点2（以实际用工主体定性，不以合同名义定性）：一件案件中双方签订的是《劳务合同》，但合同条款符合劳动合同必备条款、劳动者须遵守规章制度并服从管理，结合《放弃社保承诺书》、聊天记录、《律师函》及工资由公司监事发放等事实，法院认定存在劳动关系，明确劳动关系成立需同时具备人格从属性、经济从属性、组织从属性；相反对照的案件中，个体工商户主张从未实际营业、劳动者系案外人招聘管理并发放报酬，法院认定双方不存在劳动关系；另一案件中“按日计酬、有活干活没活休息”的口头用工仍被认定为事实劳动关系。
特点3（双倍工资差额：期间封顶11个月，基数取固定工资构成）：计算期间为用工满一个月的次日起至用工满一年的前一日止，最长11个月。一件案件中仲裁按含提成的16500元/月计算，法院改按固定工资构成6000元（基本工资2060元＋社保补贴790元＋保密费300元＋岗位工资1200元＋绩效工资1650元）计算，理由是“双倍工资系对用人单位的惩罚而非劳动报酬，计算标准应按每月基本工资构成计算”；另一案件中法院计算日平均工资时明确剔除社保补贴1000元；还有案件中用人单位提交了三份书面劳动合同，双倍工资差额主张全部不成立。
特点4（劳动合同原件的保管责任在用人单位）：一件案件中用人单位以《劳动合同》原件整理档案时遗失为由主张已签订，并提交《员工入职登记表》《保密协议》《员工手册确认书》及自某月起为劳动者缴纳社保佐证，法院认定其未能提交劳动合同加以证明，应承担举证不能后果。入职登记表仅有主体信息、保密协议仅约束保密义务、员工手册系单方制度文件，均缺少劳动合同期限、完整薪酬标准、解除条件等核心条款，不能替代书面劳动合同。
特点5（工资标准认定的证据顺位与自认效力）：证据顺位大体为劳动合同约定→工资表分值明细→银行流水与发放备注→社保及公积金缴存基数→聊天记录中当事人自认。一件案件中用人单位主张月工资5000元，但其负责人在微信中对按月工资10000元核算的欠薪金额未持异议并表示同意支付，法院据此支持10000元/月；另一案件中劳动者主张月工资5000元但未提供证据，法院按其认可的公司主张认定基本工资3500元加每辆15元提成；还有案件中双方长期以合同约定的5500元作为社保和公积金缴存基数，与合同约定相互印证，成为认定单方降薪未协商一致的重要依据。
特点6（社保约定无效但补缴后可请求返还）：约定不缴社保、由用人单位按月发放社保补贴的处理违反法律强制性规定而无效；用人单位补缴社保后，可请求劳动者返还社保补贴并支付用人单位垫付的社会保险个人承担部分，依据为《中华人民共和国劳动法》第七十二条与《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》第十九条。审查细节：社保补贴须在工资表或工资条中单列方能与劳动报酬区分；补缴须有社保缴费凭证；个人应缴总额以社保经办机构核算为准；劳动者事后主张签字系胁迫或空白签字的，须提供报警记录、投诉记录、录音等证据。
特点7（经济补偿与赔偿金基数口径不同，年限折算有固定规则）：同一案件中双倍工资差额基数按固定工资6000元，而经济补偿按劳动者在仲裁中自行主张的16500元/月计算0.5个月，法院以“系自身权利的自由处分”为由认可，这是全案群中最易出错之处。另有案件按离职前月平均工资6089元×1.5个月计算经济补偿（工作超一年不满一年半按1.5个月），有案件按1.5个月×6084元计算，有案件因实际履行期限不满12个月而按实际履行期间的月平均工资计算。关于违法终止：判断用人单位单方解除（终止）行为合法性时，应当以用人单位向劳动者发出的解除通知所载内容为认定依据；用人单位在诉讼中另行提交审计报告、经营困难材料主张“客观情况发生重大变化”，不能替代通知载明的理由，也不能补足其作出决定时未履行的法定程序；连续订立两次固定期限劳动合同、劳动者在第二次合同期满前书面要求续订无固定期限劳动合同而用人单位仍以“合同期满不再续订”终止的，构成违法终止。
特点8（未休年休假：按当年度已工作时间折算，累计工作年限决定天数，单位负安排举证责任）：折算天数按当年度已工作时间占全年比例计算并保留小数位，不随意取整；累计工作年限由劳动者以社保缴纳记录证明；日工资口径为剔除加班工资后的月平均工资除以21.75，按200%计算；用人单位未举证证明已安排年休假的，承担不利后果。
特点9（加班工资按考勤逐月统计、按法定倍数计算并逐笔扣减已付部分）：按考勤表分别统计休息日加班与延时加班小时数，对用人单位主张的已付标准予以核实并从应付额中扣减；休息日当日已据实发放工资的，该部分按100%补差；延时加班已按约定标准支付的，按150%减去已付部分补差。加班时长以用人单位掌握的考勤表为准，用人单位不提供的承担不利后果；用人单位以“打包工资已包含加班费”抗辩的，须核对折算后是否低于法定标准；扣发工资须有合法依据，否则应返还。
特点10（工伤待遇：参保不等于免责，举证责任在主张免责的一方）：总承包单位以项目名义参加工伤保险，主张其仅为参保单位而非用人单位，但逾期未能提交劳动者在参保范围人员名单之内的证据，法院对其“因劳动者自身原因未办理工伤保险理赔”的理由不予采信，判令其支付全部工伤保险待遇并逐项列明计算方式：一次性伤残补助金按统筹地区职工月平均工资×60%×伤残月数，一次性工伤医疗补助金与一次性伤残就业补助金按统筹地区职工月平均工资×对应月数，停工留薪期工资按本人受伤前月平均工资×月数，医疗费、住院伙食补助费（按天）和鉴定费据实；裁判参照《安徽省实施〈工伤保险条例〉办法》相关条文。审查细节：须分别锁定“统筹地区上年度职工月平均工资”与“本人受伤前月平均工资”两个基准，工伤待遇明细须逐项列示而非只写总额。
特点11（用人单位内部制度和内部标准具有可援用的证明力）：用人单位在系统内公布的差旅费报销标准，即使其主张实际未按此执行，法院仍按该标准判付出差补贴；用人单位以《薪酬管理办法》及党员大会签到表主张劳动者已知悉降薪的，法院指出劳动者固定工资在该办法出台前即已降低，不认可协商一致，且劳动者未提出异议不能视为默认。审查细节：内部标准一经公示即可成为劳动者主张权利的依据，“未实际执行”的抗辩不成立。
特点12（事实推定规则）：按银行流水的首笔转款时间结合“当月发放上月工资”的发放习惯，推定劳动关系自次月起成立，对劳动者主张的更早入职日以缺乏证据为由不予采信；劳动者离职多年后申请仲裁被以超过仲裁时效不予受理后，法院仍就确认劳动关系之诉进行实体审查，说明确认之诉不因仲裁时效而当然被阻断。
特点13（程序性审查要点相对固定）：仲裁前置与不予受理通知书的处理贯穿多数案件，不予受理理由包括主体不适格、已达退休年龄、已超仲裁时效；经合法传唤未到庭的，视为放弃质证和抗辩权利，承担不利法律后果；劳动者与用人单位均不服同一仲裁裁决分别起诉的，依《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第四条并案审理、互为原被告、一并裁决。“股东身份＋劳动关系”并存情形下，应以实际履行的用工事实判断。
三、审查要点与举证责任分配核心结论。由用人单位掌握管理而不提供的证据，用人单位承担不利后果：劳动合同（未提供按未签订处理）、考勤记录（加班时长）、工资表与工资发放记录、已安排年休假的记录（未提供按应休未休支付200%工资）、参保人员名单（未能证明在名单内的承担全部工伤保险待遇）。须由劳动者自行举证的：累计工作年限（社保缴纳记录）、实际提供劳动、解除意思表示及其理由（被迫解除通知书及邮寄凭证）、工资标准高于用人单位认可标准的事实、确认劳动关系的事实基础。
四、合格参考答案的核心判断。（1）台账中每条案件、每个请求项均有来源定位，全部金额均可用公式复算，与裁判主文的差异单列说明；（2）至少形成定性、基数、举证、程序四个维度上的横向比较，并对同一维度内不同处理结果的案件列出可验证的差异变量（主体资格、实际用工主体、合同原件有无、工资构成有无分项、是否有当事人自认、是否明确提出解除、是否有书面续订要求、考勤是否在单位手中）；（3）裁判特点数量有限且可验证，每条写明成立条件与反例，不把个案表述概括为普遍规则；（4）材料清单落到动作层面，标明哪些属于“无法取得即承担风险”的项；（5）附件没有记载的事项保持空缺或标记异常，没有执行或履行材料时不对实际回款、社保补缴到账或档案转移完成作肯定结论。 |
